- 몬스터 공격에만 100% 데미지가 들어가며 팀킬이 완전히 차단되었습니다.
[v5.6] 게임 재입장 & READY 시스템 패치
- 🔄 게임 초기화 강화: 솔로/협동 모드에서 나간 뒤 다시 들어와도 이전 라운드, 몬스터, 골드, 다이스, 투사체가 남지 않습니다.
- 🧹 이전 게임 정리: 나가기 시 예약된 몬스터 생성과 게임 루프까지 함께 초기화되어 새 게임이 완전히 새로 시작됩니다.
- 🚩 1라운드 연출 개선: 게임에 들어오면 먼저 ROUND 1 배너가 표시되고 잠시 후 몬스터가 등장합니다.
- 🤝 협동 READY 시스템: 두 플레이어가 모두 READY를 눌러야 협동 전투가 시작됩니다. 한 명이 준비하지 않았으면 몬스터가 먼저 나오지 않습니다.
- 🤖 AI 봇 협동: 봇 모드도 READY 화면을 거친 뒤 전투를 시작합니다.
[v5.10] 개발자 모드 & 협동 초대 수정 패치
- 🛠️ 개발자 모드 활성화 안내 변경: 개발자 모드를 켜도 화면 중앙에 "000님이 개발자모드를 활성화" 같은 별도 안내가 뜨지 않습니다.
- 📋 개발자 모드 메뉴: 개발자 모드를 활성화한 뒤 로비의 개발자 모드 버튼을 다시 누르면 메뉴가 열립니다.
- 📢 공지하기: 메뉴에서 공지를 입력하면 로비 상단에서 고정된 긴급 공지 영역에 표시됩니다.
- 🛑 개발자 모드 끄기: 같은 메뉴에서 개발자 모드를 바로 끌 수 있습니다.
- 🤝 협동 초대 수정: 이제 초대 버튼을 눌러도 초대한 사람이 즉시 게임에 들어가지 않습니다. 상대방이 초대창에서 수락해야만 게임 연결 및 READY 화면으로 진입합니다.
- ❌ 초대 거절: 상대가 거절하면 게임에 입장하지 않고 로비에 그대로 남습니다.
[v5.12] 긴급 공지 & 협동 매칭 안정화 패치
- 🚨 긴급 공지 영역: 로비의 긴급 공지를 모든 이용자에게 표시할 수 있도록 추가되었습니다.
- 👥 소셜 / 로비 채팅: 현재 접속자와 로비 채팅 기능이 추가되었습니다.
- 🛠️ 개발자 모드: 로비에서 개발자 공지를 등록하고 협동 게임의 배속을 팀원과 동기화할 수 있습니다.
[v5.16] 협동 HOST 권위 월드 동기화 & 팀원 게임 진입 안정화
- 👑 게임 HOST 분리: 로비 HUB와 실제 게임 HOST를 완전히 다른 역할로 취급하도록 협동 연결 구조를 안정화했습니다.
- 🎮 HOST 권위 게임 월드: 매칭된 플레이어 중 HOST 1명이 몬스터/웨이브/타워 상태를 기준으로 진행하고 팀원은 동일한 월드를 동기화합니다.
- 👾 팀원 몬스터 미출현 수정: GUEST 화면에서 몬스터가 안 나오거나 빈 게임이 되는 문제를 수정했습니다.
- 🔄 게임 시작 동기화: GUEST가 HOST의 실제 게임 시작 상태와 첫 월드 스냅샷을 확실히 받을 때까지 동기화하도록 보강했습니다.
- 📡 월드 재요청: 팀원의 월드 데이터가 끊기거나 초기화된 경우 HOST에 최신 게임 월드를 다시 요청할 수 있도록 추가했습니다.
- 🛡️ 중복 웨이브 방지: COOP GUEST가 자체적으로 몬스터를 생성하거나 라운드를 진행하지 않도록 차단했습니다.
- 🧹 게임 초기화 안정화: 이전 게임의 몬스터/투사체/웨이브 상태가 다음 협동 게임에 남지 않도록 초기화 흐름을 보강했습니다.
- 📜 이전 공지 유지: v5.5, v5.6, v5.10, v5.12, v5.13, v5.14, v5.16의 기존 공지 및 수정 내역은 그대로 유지됩니다.

[v5.15] 협동 게임 팀원 몬스터/월드 동기화 긴급 수정
- 🐛 팀원에게 몬스터가 안 보이던 문제 수정: HOST와 GUEST가 각자 웨이브를 생성하던 구조를 제거하고, HOST가 생성한 월드만 협동 게임에서 사용하도록 수정했습니다.
- 👑 HOST 권위 웨이브: 몬스터 생성, 이동, 라운드 진행은 HOST가 담당하며 팀원은 동일한 월드 상태를 받아 표시합니다.
- 🌐 실시간 월드 동기화 강화: 몬스터 위치/체력/종류, 라운드, 타워 체력을 지속적으로 팀원에게 전송합니다.
- 🚫 GUEST 중복 웨이브 생성 방지: 팀원이 게임 시작 직후 자체적으로 ROUND를 생성하여 몬스터가 없거나 서로 다른 상태가 되는 문제를 차단했습니다.
- 🎮 협동 게임 시작 안정화: READY 완료 후 HOST가 게임을 시작하면 팀원은 같은 세션의 1라운드 월드를 받아 정상적으로 전투를 시작합니다.
- 🧹 이전 v5.14 이하 공지 유지: v5.5, v5.6, v5.10, v5.12, v5.13, v5.14의 기존 공지 및 수정 내역은 그대로 유지됩니다.
[v5.14] 협동 매칭 허브/나가기 안정화 & 추가 버그 수정 패치
- 🛰️ HUB 매칭 버그 수정: 이제 방장 HUB만 매칭 상대를 발견하던 문제를 수정했습니다. HUB가 각 이용자의 매칭 신호를 다른 이용자에게 정상 중계하여 일반 이용자끼리도 서로 매칭됩니다.
- 🎮 매칭 후 게임 진입 안정화: 매칭 상대를 찾은 뒤 실제 P2P 게임 연결이 완료될 때까지 상태를 유지하고, 연결이 완료되면 READY 화면으로 정상 진입합니다.
- 🚪 나가기 버튼 수정: 매칭/연결 중 나가기를 눌러도 화면이 멈추거나 매칭 상태가 남지 않도록 연결, 타이머, READY 상태를 모두 정리합니다.
- 💬 나가기 안내 메시지: 정상적으로 로비로 돌아오면 “정상적으로 로비로 나갔습니다” 시스템 메시지가 표시됩니다.
- 🧹 매칭 취소 정리 강화: 매칭 취소 시 진행 중인 WebRTC 연결 시도와 매칭 타이머까지 즉시 종료됩니다.
- 🔄 로비 상태 복구: 나간 뒤 다시 매칭을 눌러도 이전 상대/연결 정보가 남지 않고 새로운 매칭을 시작합니다.
- 🛡️ 기존 버전 유지: v5.5, v5.6, v5.10, v5.12, v5.13의 기존 공지 및 수정 내역은 삭제하지 않았습니다.
[v5.13] 협동 매칭/연결 안정화 & 전체 버그 수정 패치
- 🔧 협동 매칭 핵심 버그 수정: "매칭되었습니다" 메시지만 뜨고 실제 게임으로 넘어가지 않던 문제를 수정했습니다.
- 🔌 P2P 연결 완료 처리 수정: 연결 완료 후 READY 이벤트가 누락되던 문제를 수정하여 실제 협동 READY 화면으로 진입합니다.
- 🔁 매칭 재시도 개선: 연결 실패/시간 초과 시 매칭 상태를 복구하고 다른 상대를 다시 찾도록 수정했습니다.
- 🛰️ 로비 P2P 복구 개선: 허브 연결이 끊기거나 PeerJS 시그널링 연결이 끊겼을 때 중복 Peer 생성 없이 재연결을 시도합니다.
- 🌐 협동 월드 동기화 개선: HOST가 몬스터/웨이브 상태를 동기화하여 두 플레이어의 랜덤 생성 및 라운드가 서로 달라지는 문제를 줄였습니다.
- 🧹 네트워크 타이머 정리: 게임을 여러 번 시작/종료할 때 Ping 및 동기화 타이머가 중복 생성되는 문제를 수정했습니다.
- 🚨 긴급 공지 고정: 긴급 공지 내용이 움직이지 않고 한 자리에서 표시되도록 변경했습니다.
- 🛡️ 연결 종료 안정화: 협동 연결 종료 시 READY/동료 패널/네트워크 상태가 정상적으로 초기화됩니다.
[v5.17] 접속자 정리 & 협동 월드/나가기 최종 안정화 패치
- 🚪 게임/READY/매칭 나가기 완전 수정: 나가기 버튼의 클릭 영역과 이벤트를 강화하고, 어떤 상태에서도 로비 복귀가 가능하도록 정리했습니다.
- 📡 접속 종료 즉시 반영: 로비를 떠날 때 HUB에 퇴장 신호를 보내 실시간 접속자 목록에서 즉시 제거됩니다.
- 🧹 유령 접속자 제거: 이전에 들어왔던 이용자가 남아 보이던 문제를 수정하고, HUB의 최신 접속자 목록으로 클라이언트 목록을 통째로 갱신합니다.
- ⏱️ 하트비트 정리 강화: 일정 시간 응답이 없는 이용자는 HUB에서 제거한 뒤 모든 이용자에게 최신 목록을 재전송합니다.
- 👾 협동 몬스터 동기화 강화: HOST가 연결 직후/게임 시작 직후/팀원의 요청 시 최신 월드를 즉시 전송하고, GUEST는 HOST 월드만 표시합니다.
- 🔄 월드 동기화 재요청 강화: GUEST가 초기 월드를 받지 못하면 반복 요청하고, 오래된 월드 패킷이 최신 상태를 덮어쓰지 못하도록 세션/순번을 확인합니다.
